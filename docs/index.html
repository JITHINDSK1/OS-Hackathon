THE PROBLEM

Why Memory Leaks Are Catastrophic

C gives programmers direct memory control, but unreleased heap allocations silently cripple production systems.

⚠️

Silent RAM Depletion

A leak of just 1 KB per request consumes gigabytes over hours. The OS is forced into aggressive page swapping, throttling performance before the OOM (Out-of-Memory) killer crashes the service.

💥

Double & Invalid Free Corruptions

Calling free() twice or releasing stack pointers invokes Undefined Behavior, corrupting heap metadata structures and opening exploitable security vulnerabilities (CWE-415 / CWE-761).

🐢

Heavyweight Existing Tooling

Valgrind slows execution by 20× to 50× and requires separate binary installations. ASan demands recompilation with custom flags. memtrack delivers instant diagnostics with zero runtime lag.

ARCHITECTURE

How memtrack Works Under the Hood

Four elegant steps powered by standard C11 preprocessor macros, intrusive linked lists, and POSIX threads.

01

Compile-Time Macro Interception

memtrack.h redefines malloc(sz) as tracked_malloc(sz, __FILE__, __LINE__). The compiler replaces every invocation with caller location coordinates at zero cost.

#define malloc(size) tracked_malloc((size), __FILE__, __LINE__)
02

Thread-Safe Linked-List Tracking

Inside memtrack.c, the macros are #undef'd so it calls the real libc. Each live allocation prepends a 32-byte AllocRecord node to g_head under a pthread_mutex lock.

pthread_mutex_lock(&g_lock); list_add(ptr, size, file, line);
03

Provenance-Aware Deallocation

tracked_free() searches the list. If found, it removes the record and frees both user memory and metadata. If not found, it intercepts double frees and stack pointer frees before any crash happens.

if (!rec) { fprintf(stderr, "WARNING: Invalid/double free..."); return; }
04

Automatic atexit() Exit Reporting

On the very first allocation, atexit(memtrack_report) is registered. When exit() or main() returns, the list is traversed, printing every un-freed block and saving to leak_report.txt.

atexit(memtrack_report); /* Fires automatically on termination */
